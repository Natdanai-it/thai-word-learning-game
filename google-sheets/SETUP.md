# ตั้งค่าคะแนนออนไลน์และแดชบอร์ดครู

เว็บเกมบน GitHub Pages ไม่มีฐานข้อมูลในตัว ชุดนี้จึงใช้ **Google Sheet ของครู** เป็นที่เก็บคะแนน และใช้ **Google Apps Script** เป็นตัวรับคะแนนพร้อมหน้าแดชบอร์ด ครูตั้งค่าเพียงครั้งเดียว

> หากเคยตั้งค่ารุ่น V6 แล้ว ให้แทนที่ `Code.gs` ด้วยไฟล์รุ่นนี้และ Deploy เป็น `New version` เพื่อให้ระบบรับคะแนนโหมด `AR ล่าคำ` ได้ ส่วน `Dashboard.html` ใช้ไฟล์รุ่นล่าสุดในชุดนี้

## ส่วนที่ 1 — สร้าง Google Sheet กลาง

1. สร้าง Google Sheet ใหม่ เช่น `คะแนนเกมคลังคำไทย`
2. เปิดเมนู `ส่วนขยาย (Extensions)` → `Apps Script`
3. ในไฟล์ `Code.gs` ลบโค้ดตัวอย่าง แล้ววางโค้ดทั้งหมดจากไฟล์ `google-sheets/Code.gs`
4. ที่บรรทัดต้นไฟล์ เปลี่ยน PIN สำหรับครู อย่าใช้ `2468` ต่อในการใช้งานจริง

```js
const TEACHER_PIN = "ใส่รหัสใหม่ของครูตรงนี้";
```

แนะนำให้ใช้รหัสอย่างน้อย 6 ตัว และไม่บอกรหัสให้นักเรียน

## ส่วนที่ 2 — เพิ่มหน้า Dashboard

1. ในหน้า Apps Script กดปุ่ม `+` ข้างหัวข้อ Files
2. เลือก `HTML`
3. ตั้งชื่อไฟล์ว่า `Dashboard` ระบบจะแสดงชื่อเป็น `Dashboard.html`
4. ลบโค้ดตัวอย่าง แล้ววางโค้ดทั้งหมดจากไฟล์ `google-sheets/Dashboard.html`
5. กดบันทึก

ไฟล์ใน Apps Script ต้องมี 2 ไฟล์ดังนี้

- `Code.gs`
- `Dashboard.html`

## ส่วนที่ 3 — Deploy เป็น Web app

1. กด `Deploy` → `New deployment`
2. กดรูปเฟือง แล้วเลือก `Web app`
3. ตั้ง `Execute as: Me`
4. ตั้ง `Who has access: Anyone`
5. กด `Deploy` และอนุญาตสิทธิ์
6. คัดลอก Web app URL ที่ลงท้ายด้วย `/exec`

การตั้งเป็น `Anyone` จำเป็นเพื่อให้นักเรียนที่ไม่ได้ลงชื่อเข้า Google ส่งคะแนนได้ แต่ Google Sheet ไม่ต้องเปิดเป็นสาธารณะ และหน้าแดชบอร์ดยังต้องใส่ PIN ที่ตรวจสอบฝั่งระบบ

## ส่วนที่ 4 — เชื่อมเว็บ GitHub Pages

1. เปิดไฟล์ `score-config.js`
2. ใส่ Web app URL ระหว่างเครื่องหมายคำพูด

```js
window.THAI_GAME_SCORE_API_URL = "https://script.google.com/macros/s/XXXXXXXX/exec";
```

3. บันทึกไฟล์
4. อัปโหลด `score-config.js` พร้อมไฟล์เว็บทั้งหมดขึ้น GitHub
5. เปิดหน้าเกมใหม่ แล้วกดปุ่ม `แดชบอร์ดครู` ด้านบนเพื่อตรวจสอบ

## วิธีใช้งาน

- นักเรียนกรอกชื่อ ชั้น/ห้อง และเลขที่ ดูคลิป แล้วทำภารกิจ
- เมื่อจบภารกิจ คะแนนจะส่งเข้าชีต `คะแนนนักเรียน` อัตโนมัติ
- หากอินเทอร์เน็ตหลุด คะแนนจะรออยู่ในเครื่องและลองส่งอีกครั้งเมื่อออนไลน์
- ครูเปิด Web app URL หรือกด `แดชบอร์ดครู` จากหน้าเกม แล้วใส่ PIN
- หน้าแดชบอร์ดค้นหานักเรียน กรองห้อง/บทเรียน/โหมด/วันที่ ดูสถิติ และดาวน์โหลด CSV ได้

## เมื่อแก้ Code.gs หรือ Dashboard.html ภายหลัง

1. กด `Deploy` → `Manage deployments`
2. กดรูปดินสอที่ deployment เดิม
3. ที่ Version เลือก `New version`
4. กด `Deploy`

ควรอัปเดต deployment ทุกครั้ง มิฉะนั้นลิงก์ `/exec` จะยังแสดงโค้ดรุ่นเก่า

## ข้อมูลที่บันทึก

- ชื่อ–นามสกุล ชั้น/ห้อง และเลขที่
- บทเรียนและโหมดเกม
- คะแนนที่ได้และคะแนนเต็ม
- วันที่–เวลาที่ทำ
- คำที่นักเรียนยังตอบผิด

## ข้อควรทราบด้านความปลอดภัย

- เก็บ Google Sheet เป็นส่วนตัวสำหรับครู และไม่เปิดแชร์แบบสาธารณะ
- เปลี่ยน PIN เริ่มต้นก่อน Deploy และเปลี่ยนใหม่หากรหัสรั่ว
- ระบบตรวจรูปแบบข้อมูล จำกัดชนิดบทเรียน/โหมด และกันรายการซ้ำด้วยรหัสรายการ
- เนื่องจากปลายทางรับคะแนนต้องเปิดให้นักเรียนส่งได้ ระบบนี้เหมาะกับการใช้งานในชั้นเรียนทั่วไป ไม่ใช่ระบบสอบที่ต้องยืนยันตัวตนระดับสูง
